一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 插件：用自然语言「一键」游玩《明日方舟》！

> [!TIP]
> MAA 负责稳定执行，dsh-maa-cli 让它听懂目标、编译策略、记住偏好，并根据真实反馈继续推进。

## 相比原生 MAA 多了什么

| | 原生 MAA | dsh-maa-cli |
| --- | --- | --- |
| 下达任务 | 在界面里逐项勾选、填参数 | 说一句话，生成计划，确认后执行 |
| 运行中调整 | 只能停止 | 「再打两局就停」「这次 Boss 前停」，可随时查进度 |
| 肉鸽策略 | 自己手动修改资源 JSON 文件 | 备注里写明需求「特种券优先招结城理，让他堵门」(亲测提高自动肉鸽胜率)，自动编译并记住 |
| 基建自定义排班 | 手写排班 | 「制造站全放赤金，XXX放贸易站」 |
| 抄作业 | 自己找作业、自己判断干员够不够 | 按你的 Box 自动搜索作业，失败自动换下一份 |
| 养成 | 无 | 培养建议、材料缺口计算、联合刷图规划 |
| 目标 | 无 | 「完成今天的日常，不用理智药」，按预算分步推进 |
| 出错时 | 看日志自己判断 | 区分已确认与推测的原因，安全时自动重试 |
| 安装 | 下载并配置 MAA | 首次使用自动下载独立运行时 |

## 快速开始

```text
dsh plugin --profile desktop add dsh-maa-cli
```

或

```text
dsh plugin --profile web add dsh-maa-cli
```

安装后**重启 DSH Desktop**，启动模拟器，然后试试：

```text
/maa fight                                    打开理智作战面板
帮我清理基建，再刷 20 次 1-7                    用自然语言准备计划
找一个 H8-4 低配作业，用我 Box 里有的干员打       抄作业
```

第一次执行会自动下载运行时（约 520–630 MB，通常 1–3 分钟）。

## 功能与文档

### [本地命令与面板](docs/commands.md)

日常操作不用经过模型：`/maa fight`、`/maa infrast`、`/maa recruit`、`/maa rouge` 等命令直接打开 MAA 风格的参数面板，改完点确认就执行。

- **零模型调用**：命令走 DSH 本地通道，不消耗 token。
- **记住上次设置**：每个面板独立记住上次确认的参数，肉鸽按主题分别记；MAA 更新后只回退失效的字段。
- **运行时指令**：任务运行中在面板里输入「现在停止」「再打两局就停」「这次 Boss 关前停止」「现在打到哪了」。局数、楼层只按 MaaCore 的可靠回调判断，不靠猜。
- **桌面通知**：任务完成、失败或按条件停止时弹通知，不用一直盯着。
- **安全停止**：停止只终止本次任务的进程树，确认进程真正退出后才显示「已停止」；DSH 崩溃重启后会清理残留进程。

### [自然语言与策略](docs/natural-language.md)

说一句话就能准备一整串任务，比如「先启动游戏，基建换班，再刷 20 次 1-7，最后领奖励」。

- **一次模型调用生成计划**：确认按钮在本地执行，确认时不再调用模型。
- **备注编译成真实策略**：在备注里写「优先招募结城理，让他在前方堵门」，插件会改写 MAA 实际读取的肉鸽招募表和自动战斗配置，而不是只存一段文字。执行完自动恢复原始资源。
- **自动选点**：「堵门」「守蓝门」不用给坐标，插件按地图数据和干员是地面还是高台，自动算出部署位置和朝向。
- **策略记忆**：验证通过的策略会保存下来，下次换种说法也能命中复用；冲突的要求不会执行。
- **肉鸽面板**：主题、模式、难度、分队等选项从当前 MAA 资源读取，新主题上线不用等插件更新；难度默认「MAX」自动取最高。

### [日常任务、抄作业与目标](docs/tasks.md)

- **刷理智**：只给总次数，代理倍率自动分组；支持「刷到 3 个固源岩组」这种掉落目标。
- **今日开放关卡**：「今天开了哪个芯片本就刷哪个」，按服务器 04:00 换日计算。
- **公招**：默认只确认 3★/4★，出 5★/6★ 时跳过并提醒你手动处理。
- **自然语言基建排班**：「制造站全放赤金，红云放贸易站」编译成 MAA 自定义排班，干员名会校验，没有的干员会提示。
- **按 Box 抄作业**：从 MAA 作业站搜作业，对照你的 Box 标出缺少或练度不够的干员（3 技能要精二等），能打的排前面。
- **失败自动换作业**：作业打输时自动换下一份同关作业，最多换 3 份，每次都弹通知告诉你。
- **目标驱动**：「我要培养结城理，缺什么列出来」「源岩要 20 个，总理智不超过 120」，插件读 Box 和仓库，按预算分步执行，每步确认完成才进入下一步。
- **工作流预设**：把「启动、基建、访问好友、领奖」存成预设，下次一句话复用。

### [干员与养成](docs/operators.md)

- **Box 问答**：扫描一次后直接问「哪些六星还没精二」「维什戴尔几潜」，只读缓存，不连模拟器。
- **培养建议**：参考社区强度投票的杯级，并考虑你的职业覆盖：哪个职业还没有能用的干员，就优先推荐。
- **养成规划**：精英化、等级、技能、专精、模组都能算，可以一次规划多名干员，对比仓库算出缺口。
- **够不够**：「我的仓库够不够把清流精二？」只读计算，直接回答。
- **刷图规划**：用企鹅物流的掉率和 ArkPlanner 联合优化选关；每次只刷一批，然后重新扫描仓库再规划，避免按期望值刷过头。

### [辅助插件](docs/extensions.md)

按需安装的扩展，不随本插件自动安装。用 `/maa ext` 查看状态，用 `/maa ext install <id>` 安装（确认后才会安装）。

- **[coverocr](https://github.com/nhyo/dsh-maa-coverocr)**（`dsh-maa-coverocr`，🧪 测试功能）：把 B 站作业视频链接发给模型，它会从标题、简介、标签、UP 主评论和封面识别视频用到的干员，并和你的 Box 比较，告诉你能不能抄（缺 1 名也算，可借助战），附上视频链接让你自己去抄。识别结果可能不全或有误，请以视频为准。

### [运行时与配置](docs/runtime.md)

插件自带独立的 maa-cli 运行时：首次使用时下载，每天检查一次更新（更新时面板会显示进度，失败自动回滚）。它通过独立目录与系统里的 MAA 隔离，删掉目录就能卸载。这一篇还包括环境变量、兼容的系统与模拟器，以及插件能做和不会做的事。

### [故障排查与常见问题](docs/troubleshooting.md)

模拟器连不上、运行时下载失败、确认后没反应、停止失败等情况的处理方法。插件会记录 MaaCore 回调、任务检查点和 ADB 状态，把失败原因分成「已确认」和「推测」；只有不会造成重复消耗的扫描任务才会自动重试。
