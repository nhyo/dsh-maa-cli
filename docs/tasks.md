# 日常任务、抄作业与目标

[← 返回 README](../README.md)

```text
用两瓶药刷 1-7，不要碎石
刷 3 个固源岩组
今天开了哪个芯片本就刷哪个
公招 4 次，出 5 星以上告诉我
制造站全部放赤金，红云放贸易站
找一个 H8-4 低配作业打一下
帮我完成今天的日常，不用源石和理智药
```

默认不使用源石和理智药，除非你明确要求。

## 理智作战

- 只需给总次数，代理倍率由 MaaCore 自动分组（单次最多 100 次）。
- **掉落目标**：「刷到 3 个固源岩组」会在任一物品达标时停止；面板里写 `固源岩组=3；装置=2`。
- **剿灭**：可以说「剿灭」，但插件不知道本周是否已打满。
- **周常关卡**：`maa_stage_schedule` 按服务器日（04:00 为界）列出今天开放的资源本和芯片本；选了未开放的关卡会提示。

## 公招

默认和 MAA 一样：招募 4 次，自动确认 3★/4★。**5★/6★ 不会自动确认**，会跳过并在运行面板和结果里提醒你手动处理。

## 基建排班

`maa_prepare_infrast` 把自然语言排班编译成 MAA 自定义排班：

- 干员名会校验；查不到、重复或超员的会列为「未执行」。有 Box 缓存时提示你没有的干员。
- 没提到的设施按 MAA 默认算法。
- **MAA 不会切换生产线**，只按房间当前产物挑干员。
- 排班可以保存、复用、删除。

## 抄作业

`maa_copilot` 从 [MAA 作业站](https://prts.plus) 搜作业，按你的 Box 排序：

- 标出缺少或练度不够的干员（2 技能需精一、3 技能需精二，及作业写明的要求），干员齐全的排前面。没有 Box 缓存时会说明无法判断。
- 确认面板显示标题、作者、所需和缺少的干员。保全派驻作业自动用 SSS 模式。
- **失败自动换作业**：由 MAA 自动导航到关卡的作业，准备时另挑最多 3 份同关、Box 不缺干员的备用作业。作业本身失败才换（模拟器断连、手动停止不算），每次换都会弹桌面通知。`autoSwitch: false` 可关闭。

生成的排班和作业文件只在执行期间存在，结束后删除。

## 目标与工作流

可以直接提目标，插件会读取 Box 和仓库缓存，生成受预算约束的步骤：

```text
我要培养结城理，先读取 Box 和仓库；缺什么列出来，不要直接刷。
源岩需要 20 个，库存不够时规划 1-7，但总理智不超过 120。
把「启动、基建、访问好友、领奖」保存成工作流，下次复用。
```

- 目标保存在 `goals.json`，工作流预设在 `workflows.json`。
- 每步单独执行，只有日志确认完成才进入下一步；全部完成后进入「等待目标验证」，不把「进程结束」当作「目标达成」。
- 指定 `maxSanity` 后，预计理智超出预算会在执行前阻止。

## 故障恢复

- 失败原因记录在 `runs.json`，区分「已确认」和「推测」，可在运行面板查看。
- 只有未完成过任何步骤的 Box / 仓库扫描会自动重试（最多 2 次）；作战、公招、商店、领奖、基建不会盲目重放。
- DSH 中途退出后，正在运行的工作流标为待检查，不会自动续跑不确定的步骤。
