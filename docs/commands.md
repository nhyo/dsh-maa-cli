# 本地命令与面板

[← 返回 README](../README.md)

`/maa` 命令走 DSH 本地命令通道，**不调用模型**。任务命令只打开参数面板，点「确认并执行 MAA」后才操作游戏。

## 命令

| 命令 | 别名 | 作用 |
| --- | --- | --- |
| `/maa startup` | `启动游戏` | 开始唤醒 |
| `/maa fight` | `刷`、`作战` | 理智作战 |
| `/maa infrast` | `基建` | 基建换班 |
| `/maa recruit` | `公招` | 自动公招 |
| `/maa mall` | `信用收支` | 信用收支 |
| `/maa award` | `领奖` | 领取奖励 |
| `/maa rouge` | `rogue`、`肉鸽` | 自动肉鸽 |
| `/maa reclamation` | `生息演算` | 生息演算 |
| `/maa update` | `更新数据` | 更新干员 Box / 仓库数据 |
| `/maa box` | `扫描干员Box` | 只更新干员 Box |
| `/maa closedown` | `关闭游戏` | 关闭游戏 |
| `/maa stop [RUN-… / MAA-…]` | `停止` | 停止本会话的任务，等进程树退出后才返回 |
| `/maa setup` | `安装运行时` | 提前下载私有运行时 |
| `/maa help` | `帮助` | 命令帮助 |

`/maa status`、`/maa peek`、`/maa confirm` 由面板内部使用，一般不用手动输入。旧写法（如 `/maa fight 1-7 10`）仍可用，但只用于预填面板。

## 参数面板

- 参数与选项来自当前实际运行的 MAA 版本和资源，确认前再校验一次；校验失败不会消耗确认码。
- 基础项直接显示，其余放在「高级设置」；MAA 原有的提示会显示在对应字段下。
- 未选择的可选项不会写入 MaaCore，必填项缺失会指出具体字段。

### 面板记忆

每个 `/maa` 面板独立记住上一次**确认成功**的设置（肉鸽按主题分别记）。预填顺序：命令里写的参数 → 上次确认的设置 → MAA 默认值。MAA 更新后失效的字段会单独回退为默认值。

记忆只用于零模型面板；自然语言准备的计划按计划本身执行。理智药、源石等消耗仍受资源预算限制。

## 运行面板

确认后面板变为运行面板，始终带「停止任务」按钮，显示状态、耗时、进度和退出码。

- **停止**：「停止任务」或运行面板的「×」会终止本次任务的进程树。30 秒内没退出时保持「执行中」并显示原因，可重试。MaaCore 没有可靠的暂停，所以只有停止。
- **取消**：确认面板的「×」会删除计划，确认码永久失效。
- **会话隔离**：其他 DSH 会话只能看到只读状态，不能停止或追加条件。
- **独占**：有任务运行时拒绝所有新计划，避免抢占模拟器。
- **自动刷新**：任务运行中面板每 3 秒自动更新一次状态，不会在对话里留下记录。任务结束、失败或自动换作业时还会弹桌面通知。
- **DSH 重启**：启动时按 `runs.json` 终止残留的 MAA 进程树，并把记录标为「已停止」。

## 运行时指令

任务运行中可以在面板输入框里用自然语言追加指令：

```text
现在停止
再打两局就停
这次 Boss 关前停止
取消停止要求
现在打到哪里了
```

- 局数、楼层、Boss 节点只按 MaaCore 的可靠回调判断；没有可靠数据时显示「未知」并继续等待，不会猜测。
- 新的停止条件会替换尚未触发的旧条件。
- 「接下来优先招某干员」「这把我来打」这类要求无法在运行中生效（maa-cli 没有暴露实时改参的接口），会明确提示「未应用」。请写进下一次任务的备注。
